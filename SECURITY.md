# Security policy

Please do not open a public issue for a vulnerability that exposes credentials, enables SSRF, bypasses rate limits, or can duplicate transaction submission.

Until a dedicated security mailbox is configured, use GitHub's private vulnerability reporting feature for this repository. Include affected version, reproduction steps, impact, and any suggested mitigation. Do not include real provider credentials or signed transactions.

The `main` branch and latest tagged release are supported during the portfolio phase.
